    b;

**指针**

printf("%p");输出地址
&：取地址符，右边只能放变量
指针就是保存地址的变量：int *p = &i；
*是一个单目运算符，用来访问指针的值所表示的地址上的变量

数组参数：
以下四种函数原型是等价的：
int sum(int *ar,int n);
int sum(int *,int);
int sum(int ar[],int n);
int sum(int [],int);
数组变量是特殊的指针

指针与const:
1.指针是const
表示一旦得到了某个变量的地址，不能再指向其他变量
int *const p = &i;
*p = 26; //ok
p++ //error
2.所指是const
表示不能通过指针去修改那个变量(!并不使那个变量成为const)
const int *p = &i;
*p = 26 //error
i = 26; //ok
p = &j; //ok


**字符串**

char string[n+1];
scanf("%ns",string); -->n:表示最多允许读入的字符数量，比数组大小小一

strlen：查看字符串长度
strcmp：比较两个字符串
int strcmp（const char *s1,const char *s2）
返回：0：s1 = s2;  1：s1 > s2; -1:s1 < s2
strcpy:把src的字符串拷贝到dst中
char *strcpy(char *restrict dst,const char *restrict src)
返回dst
strcat：把s2拷贝到s1的后面，接成一个长的字符串
char *strcat(char *restrict s1,const char *restrict s2)
返回s1，s1必须具有足够的空间
strchr:字符串中找字符
char *strchr(const char *s,int c)
char *strrchr(const char *s,int c)->从右开始找
